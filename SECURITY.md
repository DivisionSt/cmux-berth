# Security

## How do I report a security problem?

Privately, through GitHub: open the repo's **Security** tab and choose **Report a vulnerability**, or go straight to [the private report form](https://github.com/DivisionSt/cmux-berth/security/advisories/new). Please do not open a public issue for it.

cmux-berth is maintained in spare time, so a reply can take a few days. Fixes go out as a new patch release.

## Which versions get fixes?

Only the latest release.
